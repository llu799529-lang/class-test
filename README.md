# 课堂测试 9 · 新闻标签页

按 `ref/` 里的三张效果图还原的一个新闻列表标签页。

## 效果

- 标签栏三个标签：**最新投诉 / 官方回应 / 追踪调查**
- 选中项为红色文字 + 红色矩形边框，边框底边压在蓝色的分隔线上
- 点击标签切换下方对应的 9 条新闻列表，行首为黑色小方块
- 列表为单行显示，标题过长时按原图样式截断
