# 课堂测试 0-9 题

`课堂测试.rar` 里第 0 到第 9 题的效果图，逐个做成的 HTML 页面。每题都是一个**可点击切换的标签页 / 排行榜**组件，纯 HTML + CSS + 原生 JS，无任何依赖。

## 题目列表

| 文件 | 内容 | 标签 |
|---|---|---|
| `0.html` | 排行榜 | 新闻 / 证券 / 理财 / 博客 |
| `1.html` | 点击排行 | 点击排行 / 评论排行 |
| `2.html` | 24小时点击排行 | 实时点击 / 24小时排行 |
| `3.html` | 新车上市表 | 最新上市 / 即将上市 |
| `4.html` | 文学社科书城 | 流行小说 / 社科历史 / 文学艺术 |
| `5.html` | 影视排行 | 每日 / 每周 / 每月 / 全部 |
| `6.html` | 股票涨跌榜 | 沪涨 / 沪跌 / 深涨 / 深跌 |
| `7.html` | SUV 频道导购 | 导购 / 3-9万 / 9-17万 / 17-42万 |
| `8.html` | 音乐手机频道 | 行情 / 导购 / 新品 / 评测 |
